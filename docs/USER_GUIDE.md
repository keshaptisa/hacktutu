# Руководство Пользователя

## Что это

`Туту Рядом` — сервис коротких поездок на 1-5 дней. Он помогает быстро выбрать готовый вариант путешествия, если у пользователя есть немного свободного времени, ограниченный бюджет и желание сменить обстановку.

Пользователь не ищет билеты и отели вручную по десяткам вкладок. Вместо этого он задает несколько параметров, а сервис собирает три понятных сценария поездки.

## Для кого сервис

Сервис подойдет, если вы:

- хотите выбраться на 1-5 дней без долгого планирования;
- хотите уложиться в понятный бюджет;
- еще не знаете точное направление;
- хотите получить готовый сценарий, а не просто список билетов.

## Что нужно для начала

Перед началом работы достаточно открыть главную страницу сервиса в браузере.

На стартовом экране вы увидите:

- выбор бюджета;
- выбор длительности поездки;
- выбор настроения поездки;
- дополнительные текстовые подсказки.

## Как собрать поездку

### 1. Укажите бюджет

На первом слайдере выберите сумму, в которую хотите уложиться. Бюджет считается на всю поездку.

### 2. Укажите длительность

На втором слайдере выберите, сколько времени вы готовы потратить на поездку.

Можно выбрать короткий выезд на 1 день или небольшой отпуск на несколько дней.

### 3. Выберите настроение поездки

Сервис поддерживает несколько сценариев настроения:

- тишина;
- энергия;
- романтика;
- спонтанность;
- ночная жизнь;
- впечатления.

Можно выбрать несколько вариантов одновременно. Это помогает сервису понять, какой формат отдыха вам ближе.

### 4. Добавьте уточнения

В текстовые поля можно вписать дополнительные пожелания:

- город отправления;
- желаемую атмосферу;
- сезонное ограничение;
- особое пожелание по формату поездки.

Примеры:

- `Москва`
- `хочу спокойный исторический город`
- `нужен дневной поезд`
- `без долгих переездов`

### 5. Запустите поиск

Нажмите кнопку `ПОГНАЛИ`.

После этого сервис:

1. анализирует ваш запрос;
2. подбирает направления;
3. сравнивает транспорт;
4. собирает сценарии поездки;
5. показывает доступные варианты оформления.

## Что покажет сервис

После поиска пользователь получает три сценария поездки.

У каждого сценария есть:

- название формата поездки;
- город назначения;
- ориентировочный бюджет;
- длительность;
- тип транспорта;
- краткое объяснение, почему этот вариант подходит.

Это не длинный список одинаковых предложений. Сервис специально показывает три разные интерпретации одного запроса, чтобы было проще выбрать подходящий формат отдыха.

## Как открыть подробности сценария

Нажмите `ПОСМОТРЕТЬ` на карточке понравившегося варианта.

На экране сценария появятся:

- краткое описание поездки;
- бюджет;
- длительность;
- транспорт;
- оценка соответствия запросу;
- причины выбора;
- план поездки по дням;
- информация по отелю;
- доступные ссылки на оформление.

## Как читать экран сценария

### Блок с метриками

Показывает ключевые параметры сценария:

- сколько стоит поездка;
- сколько она длится;
- каким транспортом предлагается ехать;
- насколько хорошо сценарий соответствует запросу.

### Блок «Почему этот вариант»

Объясняет, почему система выбрала именно этот маршрут. Это помогает быстро понять логику подбора и принять решение.

### Блок «Как пройдет поездка»

Показывает короткий план поездки по дням. Пользователь может быстро оценить темп маршрута: когда дорога, когда заселение, когда основные активности.

### Блок с проживанием и оформлением

Здесь отображаются:

- подходящий отель;
- ссылки на транспорт;
- ссылки на бронирование, если они доступны.

## Как доработать маршрут

Если маршрут почти подходит, его можно уточнить без нового полного поиска.

Для этого:

1. откройте нужный сценарий;
2. найдите блок `Что можно улучшить`;
3. напишите пожелание;
4. нажмите `ДОПИЛИТЬ МАРШРУТ`.

Примеры пожеланий:

- `Хочу дневной поезд`
- `Нужен отель ближе к центру`
- `Можно чуть увеличить бюджет`
- `Хочу более спокойный ритм`

После этого сервис пересоберет выбранный сценарий под новое пожелание и покажет, что изменилось.

## Как перейти к оформлению

Если сценарий вас устраивает, нажмите `КУПИТЬ ПОЕЗДКУ`.

Откроется корзина поездки. В ней собираются все доступные ссылки на оформление:

- билет туда;
- билет обратно;
- бронирование отеля.

Если часть ссылок недоступна, сервис честно покажет, чего именно не хватает.

## Что делать, если нужной ссылки нет

Это не всегда ошибка. В некоторых случаях источник данных может не вернуть все элементы маршрута.

Если ссылки нет:

- попробуйте другой сценарий;
- уточните маршрут через `ДОПИЛИТЬ МАРШРУТ`;
- повторите поиск с другими ограничениями.

## Что делать, если сервис показывает запасной сценарий

Если живые travel-данные временно недоступны, сервис может показать запасной сценарий вместо пустого экрана.

Это сделано специально, чтобы пользователь:

- не упирался в ошибку;
- все равно понимал идею маршрута;
- мог продолжить знакомство с продуктом.

## Короткий сценарий использования

1. Пользователь выбирает бюджет и длительность.
2. Отмечает настроение поездки.
3. При желании добавляет уточнения.
4. Нажимает `ПОГНАЛИ`.
5. Сравнивает три сценария.
6. Открывает понравившийся вариант.
7. При необходимости дорабатывает маршрут.
8. Переходит в корзину и открывает доступные ссылки на оформление.

## Частые вопросы

### Нужно ли заранее знать направление поездки?

Нет. В этом и смысл сервиса: пользователь задает ограничения и настроение, а направление подбирается автоматически.

### Можно ли выбрать несколько настроений сразу?

Да. Это помогает собрать более точный сценарий.

### Что важнее: бюджет или настроение?

Сервис учитывает оба параметра одновременно. Итоговый сценарий старается сохранить баланс между стоимостью, временем и типом поездки.

### Почему показано три варианта, а не один?

Чтобы пользователь мог сравнить разные форматы одной и той же поездки и выбрать тот, который лучше всего подходит по ритму и впечатлению.

### Можно ли изменить маршрут после выбора?

Да. Для этого используется блок `Что можно улучшить`.
