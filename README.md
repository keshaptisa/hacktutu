# hacktutu

Демо-концепт сервиса `Туту Рядом` для хакатона Туту: подбор коротких поездок на выходные по бюджету, длительности и настроению.
![Uploading image.png…]()

## Что внутри

- лендинг в стилистике дочернего сервиса Туту;
- форма подбора поездки по бюджету, длительности и mood-параметрам;
- выдача из трех сценариев поездки;
- детальный экран сценария с таймлайном;
- выбор отеля и экскурсии с фото, ценой и кратким описанием.

## Текущий стек

- `index.html`
- `styles.css`
- `app.js`

## Как открыть локально

Откройте файл `index.html` в браузере.

## Ограничения текущей версии

Сейчас это фронтенд-демо с моковыми сценариями в `app.js`. Интеграция с реальным MCP/MSR или travel API Туту еще не подключена.

## Идея продукта

`Туту Рядом` помогает быстро найти поездку на 1-5 дней, когда у пользователя есть немного свободного времени, ограниченный бюджет и желание сменить обстановку. Вместо бесконечной ручной выдачи сервис предлагает уже собранные сценарии: куда поехать, как добраться, где жить и что добавить в поездку.
